Visão Geral da Solução

O projeto mitiga gargalos operacionais e vulnerabilidades a distorções materiais que comprometem a conformidade com a Seção 404 da Lei Sarbanes-Oxley (SOX). A esteira de conciliação foi construída sob uma arquitetura evolutiva escalonada para o ecossistema Databricks Serverless (Apache Spark) e integrada a uma camada cognitiva via Gemini 3.6 Flash.

1. Contrato de Tipagem (Pydantic)

Esquema de validação para forçar respostas estruturadas da inteligência artificial.

from pydantic import BaseModel, Field

class RelatorioAuditoriaSOX(BaseModel):
    status_conformidade: str = Field(description="Status geral: 'Em Conformidade' ou 'Em Risco Material'")
    acuracia_auditada_pct: float = Field(description="Percentual de acurácia global da esteira")
    diagnostico_causa_raiz: str = Field(description="Análise detalhada do desvio paramétrico identificado")
    impacto_regulatorio_sox: str = Field(description="Enquadramento do risco frente à Seção 404 da SOX")
    recomendacoes_mitigacao: list[str] = Field(description="Lista de ações prescritivas para correção do motor")

2. Conciliação Distribuída (Apache Spark)

Operação relacional executada no Databricks em processamento paralelo.

# Left Join entre Template (expectativa) e Snapshot (processado)
df_join = df_template.alias("t").join(
    df_snapshot.alias("s"),
    on="id_cenario",
    how="left"
)

# Regra de Negócio: Classificação em 3 status determinísticos
df_conciliado = df_join.withColumn(
    "status_homologacao",
    F.when(F.col("s.id_cenario").isNull(), "Não Sensibilizado")
    .when(
        (F.col("t.conta_debito_esperada") != F.col("s.conta_debito_gerada")) |
        (F.col("t.conta_credito_esperada") != F.col("s.conta_credito_gerada")) |
        (F.col("t.valor_esperado") != F.col("s.valor_gerado")),
        "Divergente"
    )
    .otherwise("Sensibilizado com Sucesso")
)
